# 添加待办改到行上的加号，菜单只留分组

0.4.1 的右键菜单里，"加待办"一共三个入口：空白处右键「在末尾添加待办」、分组标题右键「在此分组添加待办」、待办右键「在下方插入待办」。2026-11-13，维护者提出改为"菜单只管分组，待办靠行上的加号"：鼠标移到条目上，名字右边露出一个「＋」，点它就在这个条目下方插一条待办。

## Context

- 菜单是分层级的（空白 / 行 / 详情面板行），每个"加待办"入口各有一套缩进规则：空白处顶格、分组标题看组内第一条待办的缩进、待办插在自己整棵子块之后。用户要添加一条待办，得先想"我要加在哪、该用哪个菜单"。
- 拖动的把手已经在行右缘（0.4.0），悬停现身的交互在这个 app 里是既有语言；加号挂在同一处，读起来是"这一行能做什么"，而不是"这个空白区能做什么"。
- 空白菜单原来还有「退出」，但顶栏的 ✕ 早就能退出，同一件事两个入口。
- 空清单上没有任何行可以悬停，加号无从发现，得有一句话把人领到第一个动作上。

## Decision

1. **行内加号取代菜单里的添加待办**：悬停在分组标题或待办上时，把手左侧 22px 处出现 12px 的加号；点它在条目下方插一条待办并进入内联编辑。落点与缩进由纯函数 `md.todoBelow` 决定——分组标题取组内第一条待办的缩进（`md.groupTodoIndent`，与 Tk 的 `_next_todo_indent` 同一语义；扫描先撞上空行或下一个分组标题就顶格），待办插在整棵子块之后（`subtreeEnd-1`），不抢子项。行菜单与空白菜单里的三个"加待办"入口、以及 `addTodoEnd` 本体一并删除；行菜单里那条主窗口走不到的 note 组也删掉（主列表不渲染备注行）。
2. **空白菜单只剩「在末尾添加分组」**：分隔线与「退出」删除，退出只剩顶栏 ✕。没有打开文件时这一项**保留但置灰**（`showMenu` 新增通用 `disabled`，点击吞掉且菜单不关）：缺失状态下真跑一次会写出一个只有分组的新文件，但让整项消失又看不出"这里本来有东西"。
3. **空清单给一句灰字**：没有任何可见行（含只有空行、只有被主窗口隐藏的顶格备注）时，列表里居中显示「右键空白处，添加分组」，`pointer-events:none`，右键照样落到 `#list` 弹出空白菜单。面板两栏不加提示，底部「＋」已经在那儿。
4. **详情面板的行上同样加号**：子待办行插同缩进的兄弟，备注行插同缩进的空备注（直接进编辑）；两者都落在该行整棵子块之后，缩进原样抄该行。加号元素与图标做成 `app/ui/plus.js` 共享，落点规则各窗口自己接。点击加号、两栏底部「＋」与行菜单的删除之前都先收掉未定稿编辑（`commitPending`）；加号本身按下时 `preventDefault`，否则抢走编辑框焦点、blur 提交重画之后 click 已经落空。

## Considered Options

- **保留菜单里的加待办，只加行内加号**：两套入口长期并存，缩进规则各写一份，用户还是得选"用哪个"。否决。
- **加号放在把手右侧或行末**：把手已经在右缘，再往右就出界；放行末会随文字长度跳动。否决。
- **缺文件时整项消失**：菜单会变成空菜单（只有一条时更没法弹），且看不出"这里本该有功能"。否决。
- **空清单不做提示**：两步走（先加分组、再用加号）对新用户是死路。否决。

## Consequences

- 菜单从"能加一切"退化为"只改结构"，添加待办的可发现性完全押在悬停加号上：空清单提示与新建文件的示例文案（`app/ui/starter.js`）承担第一次引导。
- 悬停让位从 20px 加到 40px，`label` 右内边距 42→64px、分组标题 40→62px；拖动中与编辑中的行不显示加号（编辑中的行连把手也不显示）。
- 面板加号、底部「＋」与行菜单删除共用 `commitPending`：面板编辑未定稿时先提交再动作，否则主窗口回推的那一轮数据会被 `onPanelData` 吞掉、新行进不了编辑。这是修掉一个既有的隐形路径，不只是给新按钮用。
- main 窗口的"点加号时正有别的行在编辑"这条路径要单独护住：加号按下时 `preventDefault` 不让焦点转移，插入动作再交给 `insertLine → renderList → closeEditor` 静默提交旧编辑。
- `README.md`、`GLOSSARY.md`（新增「加号」词条）、`app/PARITY.md` §2/§3 与新建文件的示例文案都按新行为改写，不再保留旧的菜单措辞。
- 跳过纯函数测试的部分（加号显隐、置灰项的点击吞没、空清单提示的出现条件）没有 DOM 接缝，验收靠实机手测。
