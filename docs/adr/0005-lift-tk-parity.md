# 解除「功能与 Tk 0.2.7 完全一致」的对等约束

> _本文末条「回退路径不变」已被 [ADR-0006](0006-remove-tk-fallback.md) 取代：`todo.pyw` 与根 `build.ps1` 已从仓库删除，回退改由 git 历史与 GitHub Releases 承担。_

[ADR-0003](0003-migrate-to-tauri2.md) 换栈时用户给了两条硬约束：① 迁移后功能与 0.2.7 完全一致，不增不减；② 测试验证，不留 bug。`app/PARITY.md` 就是按约束 ① 建的验收表——逐函数对照 `todo.pyw`（0.2.7）与本实现，任何差异都要立项。

0.3.0 换栈、0.4.0 拖动排序、[ADR-0004](0004-pin-means-docked.md) 把 📌 改成「固定在桌面 / 普通窗口」之后，Tauri 2 已经全面接管，Tk 版冻结为回退路径（`todo.pyw` + 根目录 `build.ps1` 留在仓库里，不再构建部署）。

2026-11-13 用户定稿：「现在已经全面进入了 tauri2 框架，可以开始变化了。」

- 从 Tauri 2 起，**本实现是基线**；Tk 0.2.7 只是历史参照。
- 新改动不再需要「与 0.2.7 逐行为对照」才被批准；行为写清楚、测试守住、偏离记进 `app/PARITY.md` §3 即可。
- `app/PARITY.md` 的逐函数对照表保留，角色从「验收表」降为「迁移期工程记录」——它证明 0.3.0 没漏功能，也是查「某段行为当初从 `todo.pyw` 哪一行来」的索引。

## Considered Options

- **继续维持对等约束**：Tk 版已冻结，新需求只能做成"0.2.7 也成立"的样子，等于用一份不再构建的代码限制在用的代码。否决。
- **直接删掉 `app/PARITY.md`**：迁移期的证据和考古索引一并消失（AD 里大量 `todo.pyw:NNN` 行号注释就失去了对照物）。否决。
- **保留对照表、只把角色降级，解除一事另立 ADR**：表还能查，约束的解除有据可循，两者互不绑架。选中。

## Consequences

- 设计取舍按 Tauri 侧的实际情况定，不再为对齐 0.2.7 保留别扭的交互（例如 Tk 里"点标题栏提交内联编辑"这种隐性行为，仍可以按需保持或改造，但理由是体验，不是对等）。
- `app/PARITY.md` §3「有意的载体差异」即偏离清单；今后每有有意偏离追加一条并注明出处（issue / ADR），§1/§2 的对照表不再逐行维护。
- 解除后落地的第一批偏离（本次，见 [#3](https://github.com/zwxdogs/desktop-todo/issues/3)、[#4](https://github.com/zwxdogs/desktop-todo/issues/4)）：标题栏右键菜单整块取消，前两项改为顶栏常驻图标；退出只有顶栏 ✕（以及列表空白右键菜单里的「退出」）。
- 代码注释里的 `todo.pyw:NNN` 行号继续保留：它们是考古线索，不是约束。
- 回退路径不变：需要回退时仍可按 [ADR-0003](0003-migrate-to-tauri2.md) 用 `todo.pyw` + 根目录 `build.ps1` 构建 0.2.7。
