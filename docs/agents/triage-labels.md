# Triage 标签

技能按五个固定的 triage 角色说话。本文件把它们映射到本仓库实际使用的标签字符串。

| 技能里的角色 | 本仓库的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估 |
| `needs-info` | `needs-info` | 等报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格齐全，可交给 agent 独立完成 |
| `ready-for-human` | `ready-for-human` | 需要人来实现 |
| `wontfix` | `wontfix` | 不处理 |

技能提到某个角色时（例如「apply the AFK-ready triage label」），用上表对应的标签字符串。

要改词表，直接改「本仓库的标签」这一列。
